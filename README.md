## Overview
This application is a real-time multiplayer Tic-Tac-Toe game built with Node.js, Express, and WebSockets. It has been successfully deployed to Render, utilizing environment-based port configuration (`process.env.PORT`) and dynamic WebSocket protocols (`ws://` vs `wss://`) to run seamlessly in both local and cloud production environments[cite: 5, 8, 10].
